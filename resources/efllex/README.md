# EFLLex data

`EFLLex.tsv` is the EFLLex graded lexical resource created by Luise Dürlich
and Thomas François at CENTAL, UCLouvain.

- Source: https://cental.uclouvain.be/cefrlex/efllex/download/
- Paper: *EFLLex: A Graded Lexical Resource for Learners of English as a
  Foreign Language*, LREC 2018.
- License: CC BY-NC-SA 4.0
- Local changes: no changes to the downloaded TSV. TypEng derives a compact
  SQLite profile and records the source hash.

EFLLex supplies frequency profiles for A1 through C1. It does not assign an
authoritative sense-level CEFR label. TypEng's provisional level is explicitly
the first level with a non-zero attestation and is kept separate from lexical
definitions and exam membership.
