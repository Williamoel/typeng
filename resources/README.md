# Bundled Resources

[简体中文](#打包资源)

## Recommended runtime format

Normal users should not need to download or index the raw files below. Release
and hosted builds use `resources/lexicon/typeng-lexicon.sqlite3`, a compact
preprocessed database generated by `scripts/prepare_lexicon_cache.py`.

The raw ECDICT, EFLLex, and Wiktionary files described below are maintainer
inputs for rebuilding that cache or doing dictionary research. TypEng still
accepts them in source/development mode, but parsing them is no longer the
intended first-run experience.

Place release-bundled data files here. For an end-user, step-by-step Chinese
guide, see `词典安装指南.pdf` (shipped with releases) or
[docs/dictionary_setup.zh-CN.md](../docs/dictionary_setup.zh-CN.md).

## ECDICT

For a maintainer cache build, put `ecdict.csv` in this directory:

```text
resources/ecdict.csv
```

TypEng uses this file first when a user clicks a preset library button such as CET4, CET6, IELTS, TOEFL, GRE, 高考, 中考, or 考研.

Source: https://github.com/skywind3000/ECDICT
License: MIT License, as stated by the ECDICT project.

Keep the original ECDICT license notice with packaged releases. The CSV is large, so decide intentionally whether to commit it to the repository or include it only in release packages.

## EFLLex

Provides A1-C1 textbook frequency profiles for difficulty research.

```text
resources/efllex/EFLLex.tsv
```

Source: https://cental.uclouvain.be/cefrlex/efllex/download/
License: CC BY-NC-SA 4.0. Keep this data separately licensed from the MIT code.

## Wiktionary (Kaikki)

Optional, but gives the richest example sentences. About 3 GB, so it is not
included in releases — users add it themselves. Put it here:

```text
resources/wiktionary/kaikki.org-dictionary-English.jsonl
```

(It also works if placed next to the app executable.)

Source: https://kaikki.org/dictionary/English/
Download (direct): https://kaikki.org/dictionary/English/kaikki.org-dictionary-English.jsonl
License: Wiktionary content is CC-BY-SA 4.0; keep attribution with redistribution.

The repository does include `resources/wiktionary/exam-pos-index.tsv`, a compact
POS-presence derivative for 14,942 ECDICT exam candidates. It lets preset
generation validate normalized parts of speech without the raw JSONL. Missing
examples never cause an entry to be removed.

# 打包资源

发行版要打包的数据文件放在这个目录。面向普通用户的图文版中文安装指南见
`词典安装指南.pdf`（随发行包附带），或
[docs/dictionary_setup.zh-CN.md](../docs/dictionary_setup.zh-CN.md)。

## 推荐的运行时格式

普通用户不应再下载或索引下面的原始文件。发行版和网站部署应使用
`resources/lexicon/typeng-lexicon.sqlite3`，它由
`scripts/prepare_lexicon_cache.py` 在发布前统一生成。下面的 ECDICT、EFLLex 和
Wiktionary 原始文件主要供维护者重建缓存或开展词典数据研究。

## ECDICT

维护者重建词典缓存时，把 `ecdict.csv` 放在此目录：

```text
resources/ecdict.csv
```

用户点击 CET4、CET6、IELTS、TOEFL、GRE、高考、中考、考研等预设词库按钮时，TypEng 会优先使用这个文件。

来源：https://github.com/skywind3000/ECDICT
许可证：ECDICT 项目声明为 MIT License。

请在打包发行版中保留 ECDICT 的原始许可证声明。CSV 文件较大，请自行决定是提交进仓库还是只放进发行包。

## EFLLex

提供 A1-C1 分级教材频率画像，用于词汇难度研究。

```text
resources/efllex/EFLLex.tsv
```

来源：https://cental.uclouvain.be/cefrlex/efllex/download/
许可证：CC BY-NC-SA 4.0，和 MIT 代码分开授权。

## Wiktionary（Kaikki 提取版）

可选，但能提供最丰富的例句。约 3 GB，因此不包含在发行包里，需用户自行添加。放在此处：

```text
resources/wiktionary/kaikki.org-dictionary-English.jsonl
```

（放在应用可执行文件同级目录也可以。）

来源：https://kaikki.org/dictionary/English/
下载（直链）：https://kaikki.org/dictionary/English/kaikki.org-dictionary-English.jsonl
许可证：维基词典内容为 CC-BY-SA 4.0；二次分发时请保留署名。
